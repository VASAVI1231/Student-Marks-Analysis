##Student Marks Analysis Using Python

#Project Description

The Student Marks Analysis project is a simple Python project that analyzes students' marks and calculates their total, average, highest, and lowest marks.
This project helps beginners understand basic Python programming and data analysis.

#Objective

The main objective of this project is to analyze student marks using Python built-in functions and display a summary of student performance.

#Technologies Used

Python
Google Colab

#Features

Stores student marks in a Python list.
Calculates the total marks.
Calculates the average marks.
Finds the highest marks.
Finds the lowest marks.
Displays a summary of student marks.

#Implementation

The project uses the following Python functions:
sum() – Calculates the total marks.
len() – Counts the number of students.
max() – Finds the highest mark.
min() – Finds the lowest mark.
The average is calculated by dividing the total marks by the number of students.

#Sample Data

marks = [78, 85, 92, 67, 88]

#Output

Student Marks: [78, 85, 92, 67, 88]
Total Marks: 410
Average Marks: 82.0
Highest Marks: 92
Lowest Marks: 67
Summary
Total Marks: 410

Highest Marks: 92
Lowest Marks: 67

#Conclusion

This project demonstrates how Python can be used to perform basic data analysis. It helps in understanding lists, mathematical operations, and built-in functions.
